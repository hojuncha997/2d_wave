# 카메라 위치 이탈 및 HUD 동기화 문제 해결 보고서 (2026-03-24)

이 문서는 `TowerSlot.cs` (v2.1) 업데이트 이후 메인 카메라가 HUD의 좌측 하단(0,0)으로 강제 이동하거나 게임 세상이 보이지 않는 현상을 분석하고 해결 방법을 제시합니다.

---

## 🧐 현상 분석
*   **증상**: 타워 건설/철거 기능을 추가한 직후, 메인 카메라의 좌표가 HUD(Canvas)의 원점인 좌측 하단 꼭짓점으로 이동함. 이로 인해 맵과 타워, 슬롯이 화면에서 사라지고 UI만 보임.
*   **발생 시점**: `TowerSlot.cs` 스크립트 수정 및 컴파일 완료 직후.

---

## 🔍 예상 원인 및 체크리스트

### 1. 하이어라키(Hierarchy) 상의 부모-자식 관계 오염 (가장 유력)
*   **원인**: UI 버튼 및 `UIManager` 설정 과정에서 실수로 **Main Camera가 HUD(Canvas)의 자식**으로 드래그되어 들어갔을 가능성.
*   **결과**: 카메라는 이제 게임 세상의 좌표가 아닌 UI의 좌표계(Screen Space)를 따르게 되어, UI의 0,0 지점인 좌측 하단으로 고정됨.
*   **해결 방법**: `Main Camera`를 `HUD` 밖으로 꺼내어 최상위(Root) 위치로 옮기십시오.

### 2. 카메라의 Z축 좌표(Depth) 초기화
*   **원인**: 스크립트 컴파일 중 유니티 엔진의 일시적 오류로 카메라의 Transform 값이 `(0, 0, 0)`으로 초기화됨.
*   **결과**: 2D 게임에서 카메라와 스프라이트가 동일한 Z축(0)에 있으면 카메라가 사물을 비추지 못하고 공허한 배경만 보이게 됨.
*   **해결 방법**: `Main Camera`의 **Position Z값을 `-10`**으로 수동 복구하십시오.

### 3. 카메라에 잘못 추가된 컴포넌트
*   **원인**: `TowerSlot`이나 `TowerSelectionButton` 스크립트를 추가하던 중 실수로 `Main Camera`가 선택된 상태에서 스크립트가 추가됨.
*   **해결 방법**: `Main Camera` 인스펙터를 확인하여 카메라 본연의 기능(Camera, Audio Listener) 외에 불필요한 스크립트가 붙어 있다면 삭제하십시오.

---

## 🛠️ 집에서 작업 재개 시 조치 순서
1.  **Main Camera 위치 확인**: Hierarchy 창의 최상단에 있는지 확인 (자식으로 들어가 있으면 밖으로 빼기).
2.  **Transform 리셋**: Position을 `(0, 0, -10)`으로 설정.
3.  **레이어 확인**: 카메라의 `Culling Mask`가 `Everything`으로 되어 있는지 확인.

이 문제는 코드 자체의 오류라기보다 유니티 에디터의 **씬 구성(Scene Setup)** 상태가 틀어진 것이므로, 위 순서대로 점검하면 즉시 해결될 것입니다.
